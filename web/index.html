Stickman Engine

A deterministic 2D stick-figure animation engine: a JSON script in, a video out. These pages run the engine in the browser. Start the server with npm run serve.

Pages

Showcase The whole catalog with live previews: characters, looks, faces, moves, effects, sounds, places, objects, activities, story macros, camera, music, examples and rules. Copy any entry as JSON. Open the showcase → Player Play any script or story with a timeline scrubber, scene markers, the validator's issues and the timeline. Load your own JSON file. Open the player → Move editor Pose and keyframe editor for adding or changing moves; exports JSON for catalog/moves/. Open the editor → Pose viewer Inspect the named poses on every body plan, drag channel sliders, blend between two poses. Open the pose viewer →

Common commands

npm run serveThese pages at http://localhost:5173/
npm run record -- <script.json>Render a finished video with sound into out/
node tools/validate.mjs <script.json>Check a script: errors, warnings, the timeline
node tools/manual.mjs prompt --premise "..." --copyA prompt to paste into any chat app; add --lean in a chat project that has the catalog pack
npm run catalog:buildCheck catalog/ and rebuild the generated files and the AI context pack
npm run catalog:packZip the context pack for Claude Desktop into out/context_pack.zip
npm run sfx, npm run catalog:mediaMake the sounds and music clips the showcase plays
