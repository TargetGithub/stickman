# What the project needs

Items marked **Needed from Sridhar** are things Claude cannot or should not do alone. Everything else is handled during development.

## 1. Machine and tools

| Item | Status on this Mac (2026-10-15) | When needed | Action |
|---|---|---|---|
| Node.js 20+ | v20.19.3 installed | now | none |
| npm | 10.8.2 installed | now | none |
| ffmpeg 6+ | 9.0.2 installed (Homebrew) | M6 (recording) | none |
| git | repository initialized (branch `main`) | now | optional: add a remote |
| Chromium-based browser | any | M0 (preview pages) | none; the app's built-in browser works |

## 2. npm dependencies (dev only; `/engine` has none)

| Package | Purpose | Milestone |
|---|---|---|
| `@napi-rs/canvas` | Node canvas backend for recording (chosen in M0.7) | M0 |
| `@anthropic-ai/sdk` | LLM script generation | M8 |
| `ffmpeg-static` (optional) | bundled ffmpeg if Homebrew is not used | M6 |

No test framework (uses `node:test`), no bundler, no linter dependency for now.

## 3. Assets

| Asset | Default plan | Needed from Sridhar |
|---|---|---|
| Fonts | Bangers and Inter (SIL OFL) in `assets/fonts/` | done |
| SFX | Generated by `tools/sfxgen.mjs` (no licensing issues) | Optional: CC0 packs you prefer (e.g. Kenney), dropped into `assets/sfx/` |
| Music | None by default; videos work without music | Optional: royalty-free tracks safe for YouTube Content ID, with license info |

## 4. Access and secrets

| Item | When | Notes |
|---|---|---|
| `ANTHROPIC_API_KEY` in your shell environment | M8 | **Needed from Sridhar.** Set it yourself; it is read from the environment and never written to files. Estimated cost: a few cents per generated script with prompt caching |
| YouTube account | never in v1 | Upload is manual by design |
